    Dataclass and container utilities¤

    based_datatypes.data turns dataclasses into plain mappings, flattens nested mappings, and re-constructs dataclasses while overriding a few fields. It is the plumbing behind config merging, change detection and "copy this record with one value changed" flows.

    When to use it¤

    • copy_and_override: build a modified copy of an immutable or frozen dataclass.
    • container_to_dict: feed a dataclass or pydantic model to code that expects a dict.
    • flatten_dict: turn nested configuration into flat tuple keys for diffing or logging.

    Quick start¤

    Server(host='api.example.com', port=8080, tags=['prod']) Server(host='api.example.com', port=9090, tags=['prod']) True

    Re-constructing a dataclass¤

    copy_and_override(init, obj, *args, **kwargs) reads every field the source defines, applies the positional and keyword overrides, and calls the constructor. Sources may be a single instance or a tuple of instances; later sources win.

    Point(x=9, y=2) Point(x=5, y=6)

    Fields that are not part of the constructor (init=False, e.g. derived values) are copied after construction:

    Doubled(value=3, double=6)

    Generic constructors and MaskedInit¤

    When the constructor carries type parameters, MaskedInit pairs the constructor's type with the runtime class, so the call site stays typed:

    Box(item=2)

    Known limitations

    Keyword-only dataclasses and InitVar fields are not supported: the source values are passed positionally. Required fields missing from every source raise, rather than being silently defaulted.

    Converting containers to dicts¤

    container_to_dict recognises dataclass instances, pydantic models, mappings, sequences and sets. Every other object yields None.

    {Attr(name='name'): 'ada', Attr(name='roles'): {0: 'admin'}} {0: 10, 1: 20} None

    Dataclass keys become Attr instances, so they cannot collide with the string keys of a mapping that was converted inside the same structure. Recursion is on by default; pass recursive=False to keep nested objects untouched.

    {Attr(name='inner'): {Attr(name='value'): 1}}

    Self-referencing containers terminate: the recursive branch maps back to the result object already built for that container.

    True

    Flattening nested mappings¤

    flatten_dict walks mappings only; sequences are values, not paths. The result maps a tuple of keys to the leaf value.

    {('server', 'host'): 'localhost', ('server', 'ports'): [80, 443], ('debug',): True}

    Cycle handling

    A self-reference resolves to the partially-built result for that mapping, so it contributes no extra leaf. The output therefore omits the recursive key entirely rather than emitting an empty path.
