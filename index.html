    Based Datatypes Docs¤

    Welcome! 👋

    This documentation covers the based-datatypes project: a small, dependency-light library of shared Python types, typing helpers and data utilities.

    Install¤

    The package is not published on PyPI yet; install it from the Git remote:

    uv add "based-datatypes @ git+https://github.com/cloudlane-one/based-datatypes.git"

    Requires Python 3.13 or newer.

    Usage guides¤

    Each module has a task-oriented guide with runnable examples:

    • Enums String enums that render as their value in docs and logs.

    • Types and protocols Nominal strings, state markers, structural protocols and shared aliases.

    • Context variables Scoped context values with guaranteed restoration.

    • Runtime reflection Calling module, call arguments, return types and subclass trees.

    • Type reflection Resolve, compare and map type hints — including generic classes that remember their arguments.

    • Hashing Stable hashes of dataclasses, containers, functions and dataframes.

    • Data utilities Dataclass copying, container conversion and mapping flattening.

    • Descriptors Typed, cacheable properties and dual-dispatch methods.

    • Object references Persistent, URL-serialisable pointers to Python objects.

    • Distributions Which distribution or Git repository a module belongs to.
